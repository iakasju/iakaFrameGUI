## Décisions d'arbitrage appliquées (Q-1 → Q-5)

- **Q-1 — Vendoriser** : les feuilles sont **copiées** dans `src/themes/` (bundlées par
  Vite, servies `'self'`, CSP-safe). On copie le **bloc de tokens** (source de vérité) —
  **pas de réécriture de charte**. En-tête de traçabilité dans chaque fichier.
- **Q-2 — Fonts = fallback système** : les variables `--font-*` gardent leurs **piles de
  repli système** (les Google Fonts absentes tombent proprement sur le système). **Aucun
  CDN, aucune requête réseau** (CSP l'interdit). Self-host `.woff2` = itération 2.
- **Q-3 — Registre au FRONT** : `src/theme/charteRegistry.ts` (MVP). Option « remonter
  dans `@iakaframe/core` » notée pour un partage forge↔cockpit ultérieur.
- **Q-4 — 2 chartes** : Cinabre (défaut) + NaonEdge.
- **Q-5 — Re-skin de tous les écrans via variables** : les composants P1–P4 pointaient
  **déjà** exclusivement sur des `var(--…)` (zéro hex en dur dans `src/components` /
  `src/views`) → le re-skin se fait en **redéfinissant les valeurs de variables par
  charte**, sans toucher aux composants (habillage pur).

## Mapping des variables app ↔ tokens de charte

Les composants existants utilisent un jeu d'alias sémantiques app (`--bg`, `--panel`,
`--panel-2`, `--border`, `--text`, `--muted`, `--accent`, `--accent-2`, `--danger`,
`--on-accent`). Chaque charte les **définit à partir de ses tokens** :

| Alias app | Cinabre | NaonEdge |
|---|---|---|
| `--bg` | `--bg-primary` `#e8e8eb` | `--bg-primary` `#0a0a0a` |
| `--panel` | `--bg-card` `#ffffff` | `--bg-card` `#1a1a1a` |
| `--panel-2` | `--bg-deep` `#f3f3f6` | `--bg-deep` `#111` |
| `--border` | `--line` `#dcdce1` | `--line` `#2a2a2a` |
| `--text` | `--text-primary` `#141417` | `--text-primary` `#f0f0f0` |
| `--muted` | `--text-muted` `#6f6f78` | `--text-muted` `#555` |
| `--accent` (marque) | `#bd2f27` (cinabre) | `#c8a44e` (or) |
| `--accent-2` (info) | `--blue` `#2b5f9e` | `--blue` `#3498db` |
| `--danger` | `--red` `#b3261e` | `--red` `#e74c3c` |
| `--on-accent` (texte sur accent) | `#ffffff` | `#0a0a0a` |

« Un seul accent » : `--accent-2` mappe sur la couleur **sémantique info** (`--blue`),
pas sur un 2e accent décoratif — la marque reste portée par le seul `--accent`.
