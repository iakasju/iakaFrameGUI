# Cycle de documentation (état des lieux)

Principe transverse iakaframe extrait de `methode-de-travail.md` et du CLAUDE.md global
(§ « Conventions permanentes ») — le narratif reste la référence (I5).

**Politique.** Régénérer l'état des lieux (MD + HTML) à chaque changement de version ET à chaque pause/reprise ; la mémoire humaine AppFlowy en est le miroir, jamais le remplaçant.

**Déclencheur.** changement de version | pause | reprise.
